**WORKING:**
- **Base Framework**: The repository uses the open-source LangBot framework as its core engine (verified via `ARCHITECTURE.md` and repository structure: `src/langbot`, `main.py`). The project contains roughly dozens of Python files (standard LangBot footprint) and YAML config files (`src/langbot/templates/config.yaml`, `docker/docker-compose.yaml`).
- **Real-Time Search (RTS) API Adapter**: Added in `src/langbot/pkg/adapter/slack_rts_adapter.py:8`, which implements `client.search_messages(query=f"{query} in:{channel_filter}", ...)` using `user_token`.
- **RAG Registration**: Registered in `src/langbot/pkg/pipeline/rag.py`.

**PARTIALLY WORKING:**
- **MCP Server Integration**: The LangBot engine natively hosts an MCP server at `/mcp` (`pkg/api/mcp/server.py`), exposing its core API. However, the custom tools defined in the Seva plugin (e.g., `@tool("snapshot_knowledge")`) are only mocked and lack the real execution bindings to Qdrant.
- **Docker Compose**: Renamed to `setu-core` and `setu-web`, but depends on `rockchin/langbot:latest` rather than a custom built SETU image containing the newly written code.

**NOT IMPLEMENTED / FAKE:**
- **WhatsApp -> Slack Bridge**: **FAKE**. The architecture diagram in `README.md` claims WhatsApp -> Matrix Bridge -> SETU, but no adapter or bridge logic exists in the repository.
- **Hindi Voice Note Transcription**: **STUBBED**. `plugins/seva_memory/main.py:5` has an empty `handle_audio` function with a comment `# call Whisper -> translate`.
- **Alt-text Generation**: **STUBBED**. `plugins/seva_memory/main.py:10` has an empty `handle_image` function.
- **Self-Learning / Qdrant Integration**: **STUBBED**. The `snapshot_knowledge` tool (`plugins/seva_memory/main.py:15`) is completely empty and missing Qdrant client initialization or insert logic.
- **Slack Bolt / Block Kit UI**: **MISSING**. No actual Slack interactive Block Kit handlers or Canvas responses are implemented for the app.

**BLOCKERS FOR SUBMISSION:**
1. **Missing Environment Variables**: There is no `.env` file present, and critical variables (`SETU_SLACK_BOT_TOKEN`, `SETU_SLACK_APP_TOKEN`, `SETU_SLACK_USER_TOKEN`) are missing for the local instance to boot correctly.
2. **Crash on Boot (Python 3.14 incompatibility)**: Attempting to run `uv run main.py` immediately crashes because `onnxruntime==1.23.2` does not have wheels for CPython 3.14.
   ```
   error: Distribution `onnxruntime==1.23.2 @ registry+https://pypi.org/simple`
          can't be installed because it doesn't have a source distribution or wheel
          for the current platform
   hint: You're using CPython 3.14 (`cp314`), but `onnxruntime` (v1.23.2) only has
   wheels with the following Python ABI tags: `cp311`, `cp312`, `cp313`, `cp313t`
   ```
3. **Core Features are Pure Vaporware**: The main pitch (WhatsApp translation, Qdrant memory, Alt-text) consists entirely of empty `pass` blocks in `plugins/seva_memory/main.py`. Judges inspecting the source code will instantly see it is mocked.
